外部連携 & Cloudflare Tunnel 連携ガイド

curl、Home Assistant、IFTTT、Cloudflare Tunnel経由でGoogle Homeを発言させるAPIです

1. Webhook エンドポイント

以下のURL宛に POST リクエストを送信することで、任意のテキストを発声させることができます。

POST http://192.168.11.244:8080/api/say

2. curl コマンド例

curl -X POST http://192.168.11.244:8080/api/say \
  -H "Content-Type: application/json" \
  -d '{"text": "こんにちは！テスト送信です。", "device": "部屋", "voice": "ja-JP-NanamiNeural"}'

3. 後方互換エンドポイント (従来の google-home-voicetext)

curl -X POST -d "text=こんにちは、Googleです。" http://192.168.11.244:8080/google-home-voicetext

4. Cloudflare Tunnel 経由での利用 (インターネット越しの発言)

Cloudflare Tunnelの仕組み:

ポート開放不要で、Cloudflare経由で安全にこのサーバーのポート 8080 にアクセスできます。外部に公開する際は、不正呼び出しを防ぐため .my.env で WEBHOOK_TOKEN を設定し、リクエストに Authorization: Bearer <TOKEN> または X-API-KEY: <TOKEN> を付与してください。
