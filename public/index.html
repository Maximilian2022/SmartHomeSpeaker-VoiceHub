外部連携 & Cloudflare Tunnel 連携ガイド

curl、Home Assistant、IFTTT、Cloudflare Tunnel経由でGoogle Home & Alexaを発言させるAPIです
🌐 Cloudflare Tunnel 連携中

インターネット側からは、以下の URL 宛に安全に Webhook を送信できます。
※セキュリティ保護のため、Tunnel 経由では Web GUI は自動的に遮断（403）され、Webhook API のみが許可されます。

1. Webhook エンドポイント

以下のURL宛に POST リクエストを送信することで、任意のテキストを複数スピーカーで発声させることができます。

POST [宅内LAN] http://192.168.11.244:8080/api/say
POST [インターネット (Tunnel)] https://example.com/api/say

2. curl コマンド例 (複数デバイス同時指定)

curl -X POST http://192.168.11.244:8080/api/say \
  -H "Content-Type: application/json" \
  -d '{
    "text": "ご飯ができましたよ！",
    "devices": ["部屋", "リビング", "書斎"],
    "voice": "ja-JP-NanamiNeural"
  }'

3. Cloudflare Tunnel 経由の curl コマンド例 (外部からの呼び出し)

curl -X POST https://example.com/api/say \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-secret-token" \
  -d '{
    "text": "外出先からの通知です。",
    "devices": ["部屋"]
  }'

4. 後方互換エンドポイント (従来の google-home-voicetext)

curl -X POST -d "text=こんにちは、Googleです。" http://192.168.11.244:8080/google-home-voicetext
