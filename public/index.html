📖 Speech Key 取得ステップ:
  1. Azure ポータル にサインインします。
  2. 上部検索バーに「音声サービス」(Speech Services) と入力し、「作成」をクリックします。
  3. サブスクリプションとリソースグループを選択し、地域に 東日本 (japaneast) などを指定します。
  4. 価格レベルで 「Free F0」（無料プラン）を選択し、「確認および作成」をクリックしてデプロイします。
  5. リソース完成後、左メニュー「リソース管理」→ 「キーとエンドポイント」 を開きます。
  6. 「キー 1」 をコピーして上の「Speech Key」欄に、「場所/地域」（例: japaneast）を「リージョン」欄に入力します。
⚠️「テナント 'Microsoft Services' に存在しない」エラーが出る場合:
個人用 Microsoft アカウント（@outlook.jp, @gmail.com等）で直接ポータルを開いた際や、ブラウザの古い認証情報が競合している際によく発生します。
👉 対処法: ブラウザのシークレットウィンドウ（InPrivate）を開き、Azure 無料アカウント作成ページ の「無料で始める」から初期登録を行ってからポータルにお進みください。

各個人の Gemini / AI エージェントとの連携ガイド

個人の Google カレンダーや天気を Gemini でAI要約し、自宅スピーカーから喋らせる方法

サーバーに共通の API Key を置くのではなく、「各個人が使っている Gemini (Web版 / Advanced / Gems)」 にカスタム指示を与えることで、自分の予定・天気に合わせたパーソナルなAI要約アナウンスを自宅スピーカーから発話させることができます。

📋 Gemini (Gems / カスタム指示) 向け プロンプト例:
私の Google カレンダーの今日の予定と現在の天気を参照して、朝にふさわしい明るく元気な挨拶と1日のスケジュール要約（150文字程度）を作成してください。
作成後、以下の Webhook API に POST リクエストを送信して自宅のスピーカーで発声させてください。

■ 送信先 Webhook:
POST http://<サーバーIP>:8080/api/say  (または Cloudflare Tunnel の URL)
Headers: Content-Type: application/json
Body:
{
  "text": "作成したAI文章",
  "devices": ["部屋", "書斎"]
}
💡 個人のプライベートな予定やメール情報はご自身の Gemini アカウント内だけで安全に処理され、発話テキストのみがスピーカーに届きます。

📖 公開 MCP ツール仕様

                  AI が理解し自律的に呼び出すツール定義
                

                

                  

                    1. speak(text, target?, volume?, voice?, urgent?)

                    スマートスピーカーから音声を読み上げます。「ALL」で全室一斉放送も可能。
                  

                  

                    2. list_speakers()

                    家にある Google Cast, Alexa, HomePod, DLNA, ONVIF スピーカー一覧を取得。
                  

                  

                    3. get_status()

                    おやすみモード（DND）の動作状態、現在進行中のカレンダー会議名を確認。
                  

                  

                    4. set_dnd(enabled, durationMinutes?, reason?)

                    一時的な集中や睡眠に合わせてスピーカーのミュートを制御。
                  

                  

                    5. get_history(limit?)

                    直近にどんなアナウンスが流れたかを AI が把握。

homebridge-voicehub プラグイン解説書

          

          
        

        

          
          

            Smart Speaker Voice Hub を Apple HomeKit / Siri と完全連携させるための Homebridge 公式準拠プラットフォームプラグインです。Google Cast, Alexa, HomePod, ONVIF/DLNA を HomeKit から操作可能にします。
          


          
📦 1. インストール方法

          

            
推奨: Homebridge Config UI X の「プラグイン」画面で homebridge-voicehub を検索してインストール

            

              npm install -g homebridge-voicehub
              
            

          


          
⚙️ 2. Homebridge 設定例 (config.json)

          

            

              
            

            
{
  "platforms": [
    {
      "platform": "VoiceHubPlatform",
      "name": "VoiceHub",
      "host": "http://127.0.0.1:8080",
      "enableDndSwitch": true,
      "autoDiscoverSpeakers": true,
      "volumeAsLightbulb": true,
      "presets": [
        {
          "name": "ご飯できたよ",
          "text": "ご飯ができました。リビングに集まってください。",
          "target": "ALL",
          "volume": 70
        },
        {
          "name": "お風呂が沸いたよ",
          "text": "お風呂が沸き上がりました。",
          "target": "ALL",
          "volume": 60
        }
      ]
    }
  ]
}

          


          
🗣️ 3. Siri 音声操作・オートメーション活用例

          
    
            
  • 「Hey Siri, ご飯できたよ をつけて」 → 家中のスピーカーから一斉アナウンス（実行後自動OFF）
    • 
            
  • 「Hey Siri, 会議モード をつけて」 → DND 有効化（解除時に保留通知を AI が要約して読み上げ）
    • 
            
  • 「リビングの音量を 60% にして」 → HomeKit の明度スライダーと連動して音量変更
