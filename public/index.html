🔧 手動でリフレッシュトークン（Atnr|...）を取得・直接登録する場合の手順
📖 手動リフレッシュトークンの取得方法: ブラウザプロキシログインでうまく行かない場合、以下の手順でトークンを手動取得できます：
  1. ターミナルでコンテナに入り、以下を実行します:
    docker exec -it google-home-voicetext npx alexa-cookie2
    （または手元のPCのターミナルで npx alexa-cookie2）
  2. ドメイン選択で amazon.co.jp を選び、Amazon アカウントのメール/パスワードでログインします（2段階認証も可）。
  3. ログイン成功後にコンソールに表示される Refresh Token: Atnr|... をコピーします。
  4. 下記の入力欄に貼り付けて「保存」を押すか、.my.env に REFRESH_TOKEN=Atnr|... を追記してください。

Apple HomePod 連携

AirPlay 2 / RAOP プロトコル（pyatv）による HomePod / mini への高音質ストリーミング

4 台認識済み
AirPlay 有効 パスワード不要・即時再生可能

宅内の HomePod（部屋、リビング、寝室等）が検出されています。「即時発言」や「スケジュール」「Webhook」から Google Home や Alexa と同時にアナウンスできます。

⚠️ ネットワーク接続に関する重要注意:
本サーバー（Docker）と Apple HomePod は、必ず同一ローカルネットワーク（同じLAN / Wi-Fi・同一サブネット内）に接続されている必要があります（Docker は network_mode: host を推奨）。ゲストWi-Fiや別VLANなどネットワークセグメントが跨がっている場合、マルチキャストDNS（Bonjour/mDNS）が届かず、HomePod の自動検出および AirPlay 音声ストリーミングができません。

各個人の Gemini / AI エージェントとの連携ガイド

個人の Google カレンダーや天気を Gemini でAI要約し、自宅スピーカーから喋らせる方法

サーバーに共通の API Key を置くのではなく、「各個人が使っている Gemini (Web版 / Advanced / Gems)」 にカスタム指示を与えることで、自分の予定・天気に合わせたパーソナルなAI要約アナウンスを自宅スピーカーから発話させることができます。

📋 Gemini (Gems / カスタム指示) 向け プロンプト例:
私の Google カレンダーの今日の予定と現在の天気を参照して、朝にふさわしい明るく元気な挨拶と1日のスケジュール要約（150文字程度）を作成してください。
作成後、以下の Webhook API に POST リクエストを送信して自宅のスピーカーで発声させてください。

■ 送信先 Webhook:
POST http://<サーバーIP>:8080/api/say  (または Cloudflare Tunnel の URL)
Headers: Content-Type: application/json
Body:
{
  "text": "作成したAI文章",
  "devices": ["部屋", "書斎"]
}
💡 個人のプライベートな予定やメール情報はご自身の Gemini アカウント内だけで安全に処理され、発話テキストのみがスピーカーに届きます。
